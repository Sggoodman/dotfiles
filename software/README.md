# 绿色软件清单

> 原则：**本仓库只记清单和官网链接，不存安装包/二进制**。
> 安装包请通过 scoop（`windows/scoop/`）或官网获取；涉及授权的工具自行解决，
> 不要放到公开仓库（DMCA 风险 + 影响个人职业形象）。

## 系统增强

| 软件 | 用途 | 获取 |
|---|---|---|
| [Everything](https://www.voidtools.com/zh-cn/) | 全盘文件秒搜 | 官网 / `scoop install everything` |
| [Snipaste](https://www.snipaste.com/) | 截图 + 贴图 | 官网 |
| [Ditto](https://ditto-cp.sourceforge.io/) | 剪贴板历史管理 | 官网 |
| [TrafficMonitor](https://github.com/zhongyang219/TrafficMonitor) | 任务栏网速/CPU/内存悬浮 | GitHub |
| [PowerToys](https://github.com/microsoft/PowerToys) | 微软官方效率套件（取色器、批量重命名、FancyZones） | `winget install Microsoft.PowerToys` |
| [uTools](https://u.tools/) | 快捷启动器 + 插件生态 | 官网 |
